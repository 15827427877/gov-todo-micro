# 1. 文档基础信息
- SKILL 名称：Java 标准化闭环开发与测试技能
- 适用场景：Java 后端业务功能开发、接口开发、模块迭代
- 1. 文档基础信息
     SKILL 名称：Java 标准化闭环开发与测试技能
     适用场景：Java 后端业务功能开发、接口开发、模块迭代
     核心要求：开发流程严格闭环、测试流程全量闭环、可落地可追溯
     开发语言：Java
     技术栈：Spring Boot/Spring Cloud、Maven、JUnit5、Mockito、AssertJ、Postman/JMeter、Git
2. 严格闭环开发流程（全链路不可跳过）
   2.1 需求拆解与方案设计（开发起点）
   接收需求文档，明确功能边界、输入输出、异常场景、依赖接口
   输出《Java 开发设计文档》，包含：类结构、方法定义、数据库字段、异常处理规则
   设计评审通过后，方可进入编码阶段（无评审不编码）
   2.2 环境初始化与代码规范
   拉取最新开发分支，遵循 GitFlow 分支规范：feature/功能名-日期
   统一代码规范：阿里巴巴 Java 开发手册、IDEA 格式化配置、类 / 方法 / 参数注释必填
   Maven 依赖统一管理，禁止私自引入无关依赖
   2.3 编码实现（核心开发阶段）
   分层编码严格遵循：Controller → Service → Dao → Mapper
   核心业务逻辑必须抽取独立方法，禁止超大方法、冗余代码
   全局异常捕获、参数校验、日志打印（入参、出参、异常栈）标准化
   每日提交代码，Commit 信息规范：[功能模块] 功能描述
   2.4 开发自测（开发闭环必备）
   本地启动服务，验证基础功能可用性
   检查代码规范、注释完整性、依赖安全性
   完成后提交代码合并申请，进入测试闭环阶段
3. 闭环测试流程（与开发一一对应，无死角覆盖）
   3.1 单元测试（白盒测试，方法级闭环）
   测试框架：JUnit5 + Mockito + AssertJ
   测试范围：
   Service 层所有核心业务方法
   工具类、通用组件全量方法
   异常分支、边界值（空值、极值、非法参数）
   要求：单元测试覆盖率 ≥ 80%，测试用例可重复执行
   3.2 接口测试（黑盒测试，接口级闭环）
   测试工具：Postman / Swagger
   测试范围：
   所有 Controller 接口（正常请求、异常请求）
   入参合法性校验（非空、长度、格式）
   接口返回值、状态码、错误信息一致性
   输出《接口测试用例 & 结果文档》
   3.3 集成测试（联调级闭环）
   测试依赖服务连通性（数据库、Redis、第三方接口）
   验证业务流程全链路可用性（从接口入口到数据落地）
   验证并发、重复请求等场景稳定性
   3.4 测试验收与闭环
   所有测试用例执行通过率 100%
   测试问题单全部修复、回归通过
   测试负责人签字验收，开发 + 测试流程正式闭环
4. 交付物清单（流程闭环凭证）
   完整 Java 业务代码
   《开发设计文档》
   单元测试代码
   《接口测试用例文档》
   代码合并记录 + 测试验收记录
5. 闭环校验规则（强制执行）
   无设计文档 → 不允许编码
   无单元测试 → 不允许合并代码
   无接口测试 → 不允许提测
   测试不通过 → 不允许上线 / 交付
   所有阶段必须留痕，可追溯
